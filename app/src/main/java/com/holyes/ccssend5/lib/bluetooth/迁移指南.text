## 查找替换清单

为了快速迁移，可以使用以下查找替换：

| 查找内容 | 替换为 | 说明 |
|---------|--------|------|
| `private BluetoothService mService = null;` | `private BluetoothManager bluetoothManager = null;` | 替换成员变量 |
| `mService.connect(` | `bluetoothManager.connect(` | 替换连接方法 |
| `mService.start()` | `bluetoothManager.start()` | 替换启动方法 |
| `mService.stop()` | `bluetoothManager.stop()` | 替换停止方法 |
| `mService.write(` | `bluetoothManager.write(` | 替换写入方法 |
| `mService.getState()` | `bluetoothManager.getBluetoothState()` | 替换获取状态方法 |
| `mService != null` | `bluetoothManager != null && bluetoothManager.getBluetoothService() != null` | 替换判空条件 |

## 注意事项

1. **不要在 onDestroy 中停止蓝牙服务**
   - 因为是全局服务，其他界面可能还在使用
   - 只在应用完全退出时调用 `BluetoothManager.destroy()`

2. **检查是否已连接**
   - 在初始化时，先检查 `bluetoothManager.isBluetoothConnected()`
   - 如果已连接，直接更新UI，不需要重新连接

3. **Handler 的处理**
   - 每个界面仍然需要自己的 Handler
   - 如果需要切换 Handler，可以调用 `resetBluetoothService(context, handler)`

4. **状态判断**
   - 使用 `bluetoothManager.isBluetoothConnected()` 比直接判断状态更简洁
   - 使用 `bluetoothManager.isBluetoothAvailable()` 判断蓝牙是否可用

5. **主界面断开蓝牙**
   - 在主界面的 `onResume()` 方法中添加断开蓝牙的逻辑
   - 这样可以节省蓝牙资源，避免不必要的连接占用

## 示例：完整的迁移对比

### 迁移前的文件结构：
```java
public class YourActivity extends Activity {
    private BluetoothService mService = null;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        // ...
        mBluetoothAdapter = BluetoothAdapter.getDefaultAdapter();
        if (mBluetoothAdapter != null && mBluetoothAdapter.isEnabled()) {
            mService = new BluetoothService(this, mHandler);
            tryConnectLastBluetooth();
        }
    }
    
    @Override
    protected void onDestroy() {
        super.onDestroy();
        if (mService != null) mService.stop();
    }
    
    private void sendData(byte[] data) {
        if (mService.getState() == BluetoothService.STATE_CONNECTED) {
            mService.write(data);
        }
    }
}
```

### 迁移后的文件结构：
```java
public class YourActivity extends Activity {
    private BluetoothManager bluetoothManager = null;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        // ...
        bluetoothManager = BluetoothManager.getInstance();
        mBluetoothAdapter = bluetoothManager.getBluetoothAdapter();
        
        if (bluetoothManager.isBluetoothAvailable()) {
            if (!bluetoothManager.isBluetoothConnected()) {
                bluetoothManager.initBluetoothService(this, mHandler);
                tryConnectLastBluetooth();
            } else {
                // 已连接，更新UI
                updateConnectedUI();
            }
        }
    }
    
    @Override
    protected void onDestroy() {
        super.onDestroy();
        // 不要在这里 stop
    }
    
    private void sendData(byte[] data) {
        if (bluetoothManager.isBluetoothConnected()) {
            bluetoothManager.write(data);
        }
    }
}
```

   - 确认都能正常发送
